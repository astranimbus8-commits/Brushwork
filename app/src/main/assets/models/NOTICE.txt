autoseg_edgetpu_s.tflite
------------------------
Autoseg-EdgeTPU-S (fused argmax) semantic segmentation model, ADE20K 32-class variant,
from the TensorFlow Model Garden (https://github.com/tensorflow/models).
Source: https://storage.googleapis.com/tf_model_garden/models/edgetpu/checkpoint_and_tflite/vision/segmentation-edgetpu/tflite/fused_argmax/autoseg_edgetpu_s.tflite
SHA-256: 7A1F16F5DCCC387192649D9E8F36BD4A2E107BEEAB546D6AE446D05C72DD2B88
The file is shipped unmodified. At run time Brushwork loads a copy whose graph output is
rewired (in memory) to the per-class logits tensor that feeds the model's own argmax.
